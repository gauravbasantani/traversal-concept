# Traversal concept (unofficial)

A one-screen design concept by Gaurav Basantani: in a screen shaped like a Traversal session, a teammate asks Traversal to remember a line from an old runbook ("lag alerts on orders-db are noise"). Traversal drafts the memory and waits for a person. The concept adds a check to the memory card: the alert's last 30 days, where 2 of 9 fires were real. Reject asks for a reason, and the narrower draft matches all 9.

- Live page: https://gauravbasantani.github.io/traversal-concept/
- Walkthrough (43 seconds, no audio): [walkthrough.mp4](walkthrough.mp4)

Not affiliated with Traversal. The company, people and alerts are made up. Memory review as described in Traversal's public docs; replication lag per the PostgreSQL Hot Standby docs.
